# How to use

Download the iOS Shortcuts file and import it into the Shortcuts app on your iPhone. You can then run the shortcut to get a summary of your day, including weather, calendar events, and news headlines.

When waking up

To automatically trigger the shortcut every morning, you can set up an automation in the Shortcuts app. Go to the Automation tab, create a new personal automation, and select "Sleep", then choose "Wake Up" as the trigger. Finally, select the "Morning Summary" shortcut to run when the automation is triggered.
